Autonomous, reproducible and auditable evidence synthesis.

EMET Evidence orchestrates LLM agents and deterministic tools to produce systematic reviews. Every number shown to a reader is traceable to a source passage, every exclusion to a decision, and every critical check must pass before publication.

Use it for free Read the methodology

Principles

The model is used for scientific judgement. Everything else — calculations, counts, deduplication, rendering, checks — is scripted.

Full agentic, not full LLM

Agents orchestrate deterministic tools and may abstain from publishing.

Extract once, render everywhere

Structured, verified, sourced data feeds every table, chart and report without new model calls.

Evidence before narrative

The text derives from verified data; it is never the source of truth.

Independent verification

Reviewers work in separate contexts; initial decisions are preserved before adjudication.

Fail closed

A failed critical check or an exhausted budget blocks publication. Limits are documented.

No silent exclusions

Missing, not assessed, not applicable and uncertain are kept distinct. No manufactured precision.

Open by default

Code, prompts, schemas, rules, configurations, tests and shareable data are published — never copyrighted full texts, secrets or personal data.

From protocol to open data

A review is run by a small crew of specialised agents. Each has one job and its own module, works in a separate context and never sees its twin's decision. Everything that can be computed is left to scripts.

Orchestrator

main session

Conducts the review step by step from pipeline.json. Writes the protocol and commits it before the first query, runs the searches, prepares batches, launches the agents, checks their outputs and commits. Writes the page from verified data. Never does a reviewer's work itself.

dispatches batches

Screeners

screener · A ∥ B

Titles, abstracts, then full texts, against the protocol criteria. In doubt, include.

Extractors

extractor · A ∥ B

Study data, effect estimates and risk of bias, each value backed by a verbatim quote.

Graders

grader · A ∥ B

GRADE certainty of evidence for each outcome, domain by domain.

Declarations reviewers

interests · A ∥ B

Funding and links of interest of studies and authors, each linked to its source.

agreement measured by script · disagreements only

Arbiter

arbiter

Sees only the disputed items, the two decisions and the source. Decides by the protocol and the source, never by majority; when the source does not allow a decision, takes the cautious option. The raw decisions of A and B are never overwritten.

final data → page

Verifier

verifier

Did not write the page and does not know its conclusions. Checks each claim against the passage it cites. Blocking verdicts go to the arbiter; corrected claims are re-verified.

Publication gate

validate · script

Schema, provenance and critical checks. Any failure blocks publication.

Open data

review package

Page, tables, summary sheet and a shareable data package; sources referenced by identifier and hash.

Deterministic tools

python · no model call
  • search & retraction checks
  • deduplication
  • prefilter
  • kappa & agreement
  • PRISMA flow
  • quote checks
  • rendering
  • validation

Review-depth profiles (rapid, standard, and more) set which model plays each role and how much of the work is double-checked.

Honest status

EMET Evidence is at version 0.8 (development). The engine runs the reviews of its first real-world application, shoulder-surgery.eu.

  • Internal checks pass. No external scientific validation has been performed yet; benchmarking against Cochrane reviews is planned for v1.1.
  • Agreement between agents is not accuracy, and open-source code is not clinical validation.

Get started

Python ≥ 3.9, standard library only. The repository ships a real example workspace.

git clone https://github.com/emet-evidence/emet-evidence && cd emet-evidence
python3 -m unittest discover -s tests
EMET_WORKSPACE=examples/shoulder-surgery python3 -m emet.orchestrate status immobilisation
