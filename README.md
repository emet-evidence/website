# emet-evidence.com

Static one-page site presenting [EMET Evidence](https://github.com/emet-evidence/emet-evidence) (English at `/`, French at `/fr/`). No build step, no JavaScript, no external resources.

Hosted on Cloudflare Workers (static assets, `wrangler.jsonc`), deployed automatically from `main` by Workers Builds. Custom domains are set in the Cloudflare dashboard.
